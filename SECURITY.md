# Security Policy

## Reporting a Vulnerability

Please do not report security vulnerabilities through public GitHub issues.

If you discover a security vulnerability in FlowProbe, please report it privately to the project maintainer.

Please include:

- A description of the vulnerability
- Steps to reproduce it
- The affected FlowProbe version
- Any relevant logs or examples

Sensitive information such as credentials, tokens, PATs, or API keys should never be included in public issues.
